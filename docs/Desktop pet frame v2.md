# 净无欲-王涵桌面电子宠物

## 1.项目简介

这是一个基于 *《美女，请别影响我成仙》* 中师傅净无欲（王涵）的高自由度电脑（WINDOWS）桌面电子宠物。

```

├── 求投喂
│   └── 宠物进入求投喂状态，在宠物附近刷出葡萄汁图片
├── 喂食
│   └── 播放喂食动画，结束后在桌面显示豆腐图片
├── 摸头
│   └── 宠物做出开心的表情和动作（待扩展）
├── 对话
│   └── 显示对话气泡，与宠物互动（待扩展）
├── 设置
│   ├── 窗口置顶/取消置顶
│   ├── 调整宠物大小
│   └── 更多设置（待扩展）
└── 退出
    └── 关闭程序
```

### 4.2 左键交互：点击 vs 拖拽的区分机制

**问题描述**：用户按下左键时，无法判断是想点击还是拖拽。

**解决方案**：添加移动距离阈值判定（阈值：5像素）

```
用户按下左键（记录起始位置）
    ↓
用户移动鼠标
    ↓
移动距离 < 5像素？
    ├── 是 → 视为点击（不触发拖拽）
    └── 否 → 视为拖拽（进入DRAGGING状态）
```

**判定规则**：

| 条件               | 结果   | 后续动作                  |
| ---------------- | ---- | --------------------- |
| 左键按下，移动距离 < 5像素  | 点击   | 触发点击反馈（如开心表情）         |
| 左键按下，移动距离 >= 5像素 | 拖拽   | 进入DRAGGING状态，跟随鼠标移动   |
| 拖拽中松开左键          | 拖拽结束 | 播放RELEASED动画，回到IDLE状态 |

### 4.3 投喂交互流程

```
用户右键 → "求投喂"
    ↓
宠物进入 ASKING_FOOD 状态
    ↓
在宠物附近生成葡萄汁图片（可拖拽）
    ↓
用户点击/拖拽葡萄汁到宠物身上
    ↓
葡萄汁图片消失，宠物进入 FEEDING 状态
    ↓
播放喂食动画
    ↓
在宠物前方生成豆腐图片（可被用户拖拽）
    ↓
豆腐图片停留5秒后自动消失或被用户拖拽走
    ↓
宠物回到 IDLE 状态
```

**扩展预留**：

- 可添加更多投喂物品类型
- 可添加投喂成功率机制
- 可添加投喂对情绪值的影响

### 4.4 吃东西交互流程

```
用户右键 → "吃东西"
    ↓
宠物进入 EATING 状态
    ↓
播放吃猪蹄动画
    ↓
在宠物后方生成骨头图片（可被用户拖拽）
    ↓
骨头图片停留5秒后自动消失或被用户拖拽走
    ↓
宠物回到 IDLE 状态
```

## 6.打包策略

### 6.1 资源路径处理策略

| 资源类型           | 处理方式                        | 原因                 | 示例                          |
| -------------- | --------------------------- | ------------------ | --------------------------- |
| 只读资源（图片、动画帧）   | 打包进exe，运行时从`sys._MEIPASS`读取 | 这些资源不会变，随exe分发     | `assets/idle/`              |
| 运行时数据（data/）   | 创建在exe同目录或AppData           | 每次运行会生成新数据，不能放临时目录 | `data/settings.json`        |
| 输出目录（output/）  | 创建在exe同目录                   | 爬虫等输出结果，用户需要访问     | `output/videos/`            |
| 外部工具（support/） | 创建在exe同目录                   | 需要可执行文件，不能放临时目录    | `support/ffmpeg/ffmpeg.exe` |

### 6.2 资源路径函数设计

```
get_resource_path(relative_path):
    ├── 开发态 → 项目根目录下的相对路径
    └── 打包后 → sys._MEIPASS 下的相对路径

get_data_path(relative_path):
    ├── 开发态 → 项目根目录下的相对路径
    └── 打包后 → exe同目录下的相对路径

get_output_path(relative_path):
    ├── 开发态 → 项目根目录下的相对路径
    └── 打包后 → exe同目录下的相对路径

get_support_path(relative_path):
    ├── 开发态 → 项目根目录下的相对路径
    └── 打包后 → exe同目录下的相对路径
```

### 6.3 PyInstaller打包命令建议

```bash
pyinstaller --onefile --windowed --icon=pet.ico \
    --add-data "assets;assets" \
    --hidden-import PySide6.QtGui \
    --hidden-import PySide6.QtWidgets \
    --hidden-import PySide6.QtCore \
    main.py
```

**参数说明**：

- `--onefile`：打包成单个exe文件
- `--windowed`：不显示控制台窗口
- `--icon=pet.ico`：设置程序图标
- `--add-data "assets;assets"`：将assets目录打包进exe

## 9.注意事项

### 9.1 图片资源注意事项

| 事项   | 说明                                       |
| ---- | ---------------------------------------- |
| 图片格式 | 推荐使用PNG格式，支持透明背景                         |
| 图片尺寸 | 统一尺寸，建议：128x128或256x256                  |
| 图片命名 | 按状态分类，如：`idle_001.png`、`walking_001.png` |
| 引用保存 | 在代码中保存图片引用，避免被GC回收导致不显示                  |

### 9.2 打包注意事项

| 事项   | 说明                                    |
| ---- | ------------------------------------- |
| 资源路径 | 使用统一的资源路径函数，区分开发态和打包态                 |
| 外部工具 | support目录下的工具需单独打包，不能放在sys.\_MEIPASS中 |
| 控制台  | 使用`--windowed`参数隐藏控制台窗口               |
| 图标   | 准备ico格式的程序图标                          |
| 测试   | 打包后需在不同Windows版本上测试                   |

### 9.3 爬虫注意事项

| 事项                  | 说明                                                                                                                                                                                                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 反爬机制                | B站 / 抖音都有严格的 UA / 自动化指纹检测，Selenium 启动时务必：`--disable-blink-features=AutomationControlled` + `excludeSwitches: ['enable-automation']` + CDP 注入隐藏 `navigator.webdriver`；请求间隔加随机抖动。                                                                                                                   |
| 抖音主页地址 / sec_uid | 用户**不需要手工抠 sec_uid**，在 `src/main_window.py` 顶部 `DOUYIN_USER_HOME = "https://www.douyin.com/user/..."` 处直接粘贴完整的抖音个人空间 URL 即可；`DouyinCrawler.normalize_sec_uid()` 会自动抽取 `/user/` 后面的 sec_uid。                                                                                             |
| 抖音登录态与 Cookie 存放  | **共 3 处，均允许用户一键删除**（GUI 菜单：拓展功能 → 抖音 → 清除登录数据（退出登录））：<br>① `support/Chrome/Profile-Douyin/` — 便携 Chrome 的独立用户资料目录（**最完整**，含 Cookie / localStorage / 缓存 / 登录态）<br>② `data/douyin_cookies.json` — Selenium / requests 注入用的快照<br>③ `data/douyin_cookies.txt` — yt-dlp 下载时 `--cookies` 需要的 Netscape 格式。<br>**首次登录**：菜单「登录/重新登录（扫码）」→ 弹便携版 Chrome → 用抖音 App 扫码 → 回 GUI 弹窗确认「登录完成」。不需要、也绝对不应该在代码里写账号密码。 |
| 抖音下载                | 不自己手写 a_bogus/X-Bogus 签名（维护成本极高）。**统一交给 yt-dlp + cookies.txt 下载**，yt-dlp 官方长期跟进抖音签名 / 反爬维护。                                                                                                                                                                                                          |
| B站登录                | B 站空间页目前大部分内容不需要登录；WBI 签名算法在本地做。如果要抓隐私空间 / 充电内容，可复用抖音的同一套「便携 Chrome + 独立 Profile-Dir + Cookie 双快照」方案（Profile 可以不共用，建 `support/Chrome/Profile-Bilibili`）。                                                                                                                      |
| 数据存储                | 爬取得到的视频、封面等文件按平台分目录：`output/bilibili/`、`output/douyin/`；爬虫日志和 Cookie 存在 `data/` 下。                                                                                                                                                                            |
| 用户隐私                | 登录态文件（cookie.json / txt / Chrome Profile 目录）严禁提交到 Git / 打包公开共享。`.gitignore` 中 `data/*.json`、`data/*.txt`、`support/Chrome/Profile-*` 已建议忽略。                                                                                                                                                                    |
| GUI 线程隔离            | Selenium 爬虫一律跑在 QThread Worker（`src/crawler/gui_workers.py`），不阻塞主 UI；日志 / 成功 / 失败 / 需用户交互 全部走 Qt 信号，避免在 PyInstaller --windowed 打包环境下因 `input()` / 终端导致程序崩溃。                                                                                                                               |
