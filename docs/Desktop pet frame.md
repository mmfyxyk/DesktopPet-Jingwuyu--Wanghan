# 净无欲-王涵桌面电子宠物

## 1.项目简介
这是一个基于 *《仙子》* 中师傅净无欲（王涵）的高自由度电脑（WINDOWS）桌面电子宠物。

## 2.核心功能模块
### 基础模块
- **透明窗口**：无边框，背景全透明。
- **多状态动画**：包含待机，行走等多种状态，随机触发。
- **自由拖拽**：支持鼠标左键拖拽宠物到桌面任意位置， 拖动中（左键按住不松时）进入被拖动状态（图片），松开后有“松开”动画。

### 高级模块（偏向交互互动）
*暂定鼠标右键菜单显示与左键点击选择使用各功能*
- **吃东西**：”吃猪蹄“动画，后丢给用户“骨头”图片。
- **求投喂**：让用户投喂“葡萄汁”图片（会刷出来给用户的）。
- **喂食**：喂用户豆腐，给用户“豆腐”图片。

### 拓展模块 *（算DLC？）* 
- B站爬虫爬取王涵最新视频
- 抖音访问王涵个人空间（爬取最新视频：用户Cookie等参数哪来？）
- 浏览器自动访问ihan网站

## 3.技术栈规则
- **编程语言**：Python 3.13
- **GUI框架**：Pyside6
- **状态管理**：FSM(有限状态机)模式
