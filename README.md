## ⚡ 快速上手

### ▶️ 启动
- **绿色版**：双击解压目录里的 `启动宠物.bat`
- **安装包**：桌面快捷方式「桌面电子宠物」，或开始菜单里的「桌面电子宠物」

启动后一个小王涵会出现在屏幕右下角，开始她的游荡生活 😇

### 🖱 基础操作
| 操作 | 效果 |
|---|---|
| **左键**按住 > 拖 5 像素 | 拖拽宠物到桌面任意位置 |
| **左键**点击一下 | 触发开心/回应的小动作 |
| **右键**宠物 | 打开主菜单（吃东西 / 求投喂 / 喂食 / 拓展功能 / 设置 / 关于此项目 / 退出）|
| **拖拽后松手** | 播放「落地缓冲」动画 |

### 🍜 投喂流程
1. 右键 → **求投喂** → 她身边会出现一杯葡萄汁 🍷
2. 点击/拖动葡萄汁到她身上 → 她会喝掉，然后吐给你一块豆腐 🧊
3. 豆腐图会在桌面停留几秒，你可以拖走它

### 📺 拓展功能（B站/抖音）
右键 → **拓展功能 ▶**
- **爬取 B 站最新视频** — 抓取 B 站空间的最新投稿
- **抖音 ▶ 爬取抖音最新视频** — 抓取抖音主页最新视频
- **抖音 ▶ 登录/重新登录（扫码）** — 首次使用前请先扫码登录，登录态会保留在你电脑里
- **抖音 ▶ 清除登录数据（退出登录）** — 一键清理 3 处抖音登录数据（带二次确认）
- **代理设置…** — 支持 HTTP / SOCKS5h 代理，抖音爬不出来可以挂代理
- **清除隐私数据…** — 选择删除本地代理配置 / 抖音 Cookie / Chrome 用户资料 / 显示设置缓存等
- **打开 data 目录 / 打开 output 目录** — 直接在资源管理器里打开爬虫数据和下载产物

### ⚙ 设置
右键 → **设置 ▶**
- **窗口置顶**（可勾选切换）：打开后宠物永远压在最上面；关掉后她就像普通窗口一样被其它窗口盖住（看剧/打游戏/全屏会议更舒服）
- **调整宠物大小…**：高度支持 120~480 px，提供「小 180 / 中 240 默认 / 大 320」三档预设；骨头/葡萄汁/豆腐等物品会自动联动缩放
- **恢复默认设置**：一键回到「置顶开 + 高度 240 px」（带二次确认，不碰爬虫数据）

> 所有设置都自动写入 `data/settings.json`，**下次启动自动保留**。

### 📌 关于此项目
右键 → **关于此项目 ▶**
- **GitHub / Gitee**：打开对应 Release / 仓库主页
- **ihan 粉丝站 ✨**：彩蛋，浏览器打开 ihan.com.cn

## 💡 常见问题 FAQ

**Q：启动时 SmartScreen 提示"未知发布者"？**
A：正常。项目没买 EV 代码签名证书（个人用没必要），点「更多信息 → 仍要运行」即可。不影响功能。

**Q：绿色版解压后打开，宠物是空白图？**
A：请不要随意移动或重命名解压目录里的 `_internal/`、`assets/` 子目录。若出现空白图，重新解压或到 Release 重新下载对应版本即可。

**Q：抖音/爬虫菜单点了没反应？**
A：请先做一次「拓展功能 → 抖音 → 登录/重新登录（扫码）」，扫码后登录态长期有效。若依然失败，检查「拓展功能 → 代理设置…」或本地网络。

**Q：卸载后数据会保留吗？**
A：默认**保留**。卸载到最后会弹窗问你「是否同时删除 data/output/support/Chrome 用户资料？」，默认选中"否"，下次重装可以直接继续使用登录态和已下载的视频。

**Q：想自己改代码？**
A：下「源码包」或 `git clone`，装好 Python 3.13+ 后：
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
打包用：`python scripts/build_all.py --version 1.0.0`
